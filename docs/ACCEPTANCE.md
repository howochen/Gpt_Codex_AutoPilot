# 開發分期與驗收清單

## M0：架構與無 AI 模擬器
- [ ] 建立獨立 TypeScript workspace、基本測試框架、lint/typecheck
- [ ] Runner 實作完整有限狀態機，FakeCodex / FakeGit / FakeChatGPT 三種假執行器
- [ ] 10 組異常測試涵蓋取消、重複、失敗、重啟恢復、異常關閉
- [ ] 此階段禁止真實呼叫 Codex 或 Git push

## M1：本機 GUI 與執行次數
- [ ] UI 有執行次數（位於按鈕上方）、【測試連線】【執行】【自動執行】【停止自動】
- [ ] 按【執行】模擬恰好 N 次，無任務時提前停止
- [ ] 自動模式有 5 次安全上限，不受「執行次數」輸入影響
- [ ] 按停止時不開新任務，且不可重複啟動第二個 runner
- [ ] 測試 0、負數、小數、文字、101 皆拒絕

## M1A：測試連線按鈕（新增，必須先於自動化）
- [ ] 按【測試連線】不啟動 Codex 模型、不 commit、不 push、不更動遊戲程式
- [ ] 能檢測 git、gh、codex 是否可執行；確認 GitHub repo 可讀取及登入狀態
- [ ] 可指定**原始 ChatGPT 對話 URL**，驗證 URL 與頁面是否符合使用者選定目標；共享 `share` 連結不得被當作可寫入對話
- [ ] 首次要發送探測訊息前須另行明確確認；偵測指定格式的 PONG 與 probe_id 一致
- [ ] 顯示每一步 PASS / FAIL / SKIPPED / UNKNOWN；產生 JSON 報告，可一鍵複製摘要
- [ ] 對話不可用時不宣稱連線成功；測試失敗不可解除執行限制
- [ ] 使用 fake browser、mock GitHub、mock Codex 測試安全中止、逾時、重複訊息、登入失效

## M2：Git + Codex 真實整合
- [ ] 偵測 CLI 版本、登入與工作路徑
- [ ] 只在獨立分支執行；dirty tree 必停
- [ ] 能從受控 JSON 工作單呼叫一次 Codex CLI，JSONL 被正確解析
- [ ] 由腳本執行已核准測試；失敗不可 push
- [ ] Git push 只推開發分支，儲存完整 commit SHA 與變更清單
- [ ] 自動撰寫 last result JSON；提供 fixture 測試，避免測試時付費呼叫模型

## M3：GitHub Issue / PR 交接
- [ ] 從指定 repo 讀取有核准標籤的 Issue；只接受符合 Schema 的 task payload
- [ ] 產出包含 task_id、狀態、測試、commit 的摘要，可寫回 Issue/PR
- [ ] 避免重複領取同一版本任務；登入權限不足時明確報錯

## M4：ChatGPT 網頁連接器（獨立實驗）
- [ ] 使用者可以手動選擇既有對話 URL，首次先手動登入；永遠不得收集帳號密碼
- [ ] 正確辨識指定對話、帳號、等待完成、提取完整 JSON、拒絕重複與截斷
- [ ] 雙重送訊息避免機制：request_id、最近送出訊息指紋；逾時後不盲目重送
- [ ] 當頁面變動、平台拒絕自動化、出現驗證或權限問題時立即停止並切回穩定工作單模式
- [ ] 必須在允許的環境完成端對端測試才可標示可用；若不可行，明確說明限制，不做繞過

## M5：全流程壓力驗證
- [ ] 以假 Codex 執行 10 任務、模擬測試失敗、Git 衝突、取消、系統重啟
- [ ] 真實測試至少 1 個無風險小任務；結果同步至 GitHub 開發分支
- [ ] 記錄未解問題、總使用量、每次任務的完整可追溯性
- [ ] 所有高風險操作均有使用者核准關卡

## 最終交付
Windows 可執行程式、原始碼、安裝與設定指南、測試報告、已知限制清單、對話連接器是否真正通過端對端測試的結論。
